#  Sales Dashboard 2026 (Excel Project)

##  Project Overview
This project is an interactive **Sales Dashboard** built using Microsoft Excel.  
It helps analyze sales performance across different regions, products, and salespersons.

---

##  Objectives
- Track overall sales performance
- Analyze profit and units sold
- Compare regional and product-wise sales
- Evaluate salesperson performance

---

##  Key Metrics (KPIs)
-  Total Sales
-  Profit
-  Units Sold
-  Average Sales

---

##  Dashboard Features
- Dynamic **Slicers** (Region, Product, Salesperson)
- Interactive charts:
  - Line Chart (Units Sold)
  - Bar Chart (Salesperson Performance)
  - Donut Chart (Region-wise Sales)
  - Horizontal Bar (Product-wise Sales)
- Clean and user-friendly design

---

##  Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Slicers for interactivity
